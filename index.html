What is this Platform?

This Learning Management System (LMS) is a modern web-based platform that helps educational institutions create courses, manage students, deliver assessments, and issue certificates — all powered by artificial intelligence.

Unlike traditional LMS platforms, this system can automatically generate course content, create exam questions from lessons, grade essays and code submissions using AI, and produce visual slide presentations — dramatically reducing the time instructors spend on content creation.

AI-Powered

Content, assessments, slides, and grading all enhanced by AI

Multi-Institution

Supports multiple organizations with isolated data and branding

Enterprise Security

JWT auth, encryption, rate limiting, XSS protection, and more

Getting Started

Logging In

Open the Platform URL

Your administrator will provide you with the web address (URL) to access the platform. Open it in any modern browser (Chrome, Firefox, Safari, or Edge).

Enter Your Credentials

On the login page, enter your email address and password. These credentials are provided by your institution's administrator.

Access Your Dashboard

After successful login, you'll be redirected to your personalized dashboard. The interface changes based on your role (Admin, Teacher, or Student).

Tip: If you forget your password, contact your institution's administrator to reset it. For security, passwords are encrypted and cannot be retrieved — only reset.

User Roles

The platform supports five distinct user roles, each with specific permissions and capabilities.

Admin

Full system control. Manages institutions, all accounts, courses, enrollments, references, and teacher assignments.

  • Create & manage institutions
  • Manage all user accounts
  • Full course lifecycle control
  • Bulk operations (import/enroll)
  • System-wide visibility

Staff

Institution-scoped account management. Can create and manage users within their own institution only.

  • Create teacher/student accounts
  • Manage institution members
  • Scoped to own institution

Teacher

Monitors assigned courses, tracks student progress, reviews essay/code submissions, and identifies at-risk students.

  • View assigned course content
  • Monitor student progress
  • Review & override AI grades
  • At-risk student detection

Developer

Course content creator. Has full access to course building tools including AI generation, but limited to own content.

  • Create & edit courses
  • AI content generation
  • Build assessments

Student

Browses courses, enrolls, learns content, takes mixed assessments (MCQ + essay + code), and earns certificates.

  • Browse & self-enroll in courses
  • Read lessons & watch videos
  • Take mixed assessments
  • Track progress & earn certificates

Managing Institutions

Institutions are the organizational units of the platform. Each institution has its own branding, members, and courses.

Navigate to Institutions

From the Admin sidebar, click "Institutions" to open the institution management panel.

Create a New Institution

Click "Add Institution" and fill in: Name, Code (short uppercase identifier), Type, Region, Contact details. You can also pin a location on the map.

Upload or Generate a Logo

Upload your institution's logo, or click "AI Generate Logo" to have the platform create 3 professional logo options based on your institution's name and type.

Manage Institution Status

Toggle an institution's active status. Deactivating an institution blocks all its members from logging in — useful for compliance or suspension scenarios.

AI Feature: The platform can generate professional logos using AI. It creates 3 options for you to choose from — no graphic designer needed.

Managing Accounts

Create and manage user accounts for all roles. Supports individual creation and bulk import from Excel files.

Individual Creation

  1. Click "Add Account"
  2. Enter email, full name, and select a role
  3. Assign to an institution (optional for admin role)
  4. Set a temporary password
  5. Click Save

Bulk Import

  1. Download the Excel template
  2. Fill in rows: email, name, role, institution code
  3. Click "Import" and select your file
  4. Review the preview table
  5. Confirm to create all accounts

Security: All passwords are encrypted using BCrypt (work factor 12) before storage. Even administrators cannot see user passwords — they can only reset them.

AI-Powered Content Generation

The platform's AI capabilities dramatically reduce course creation time from weeks to hours.

Module Outline Generation

AI analyzes your course description and generates a structured module outline with titles and learning objectives. One click to create your entire course skeleton.

Full Lesson Content

Two-pass AI system: first generates lesson outlines with briefs, then writes complete HTML content (500-900 words) for each section with proper structure, examples, and code blocks.

Thumbnails & Visuals

AI generates unique thumbnail images for each module and background images for slide presentations using Stable Image technology.

Slide Deck Generation

Automatically creates visual slide presentations from lesson content. AI designs the layout, generates background images, and renders a PDF slide deck you can present or share.

MCQ Exam Questions

AI reads your lesson content and generates multiple-choice questions with options, correct answers, and explanations. Automatically deduplicates to avoid repeats.

Essay/Activity/Code Items

AI analyzes content type and generates appropriate items: essays for theory, activities for procedures, code challenges for programming — each with a structured grading rubric.

How AI Generation Works

  1. Select sections — Choose which lesson sections to generate from (checkboxes in the left panel)
  2. Choose generation mode — MCQ Only, Essay/Activity/Code, or Auto (Both)
  3. Click Generate — AI processes each section in parallel for speed
  4. Review results — Items appear in the right panel. Edit, delete, or keep as-is
  5. Items are ready — They're automatically added to your assessment item bank

Assessment Builder

Create mixed assessments that combine multiple question types in a single exam.

Create an Assessment

Set title, description, total items, passing score (%), time limit (optional), and maximum attempts allowed.

Assign Source Modules

Choose which modules contribute questions. Set weights to control how many items come from each module (proportional distribution).

Mixed Item Types

The assessment pulls from all item types in the bank: MCQ, Essay, Activity, and Code. Students get a mix based on what's available in the assigned modules.

Publish

Set status to "Published" to make it available to enrolled students. Items are randomly selected each attempt, so no two attempts are identical.

Teacher Dashboard

Teachers see their assigned courses and can monitor every enrolled student's progress.

View Assigned Courses

Your dashboard shows all courses assigned to you by the admin. Click any course to view its content (read-only), modules, and slide decks.

Monitor Students

Click "Students" on any course to see enrolled students with progress bars, assessment scores, and completion status.

Student Tracker

The consolidated Student Tracker shows all your students across all courses. It automatically flags at-risk students based on: low progress, suspended status, or failed all assessment attempts.

View Assessment Details

Click any student to see their per-question answers across all attempts — including which MCQ they got right/wrong and their essay responses.

Essay & Code Review

The platform's AI automatically grades essay, activity, and code submissions. Teachers can review and override any score.

Navigate to Essay Review

On the Teacher Dashboard, find the "Essay & Activity Review" section. It shows all submissions across your assigned courses.

Filter by Status

Filter submissions by grading status: Pending (not yet graded), AI Graded (needs review), or Teacher Reviewed (already overridden).

Review AI Grading

Click any submission to see: the student's full response, AI score, per-criterion rubric breakdown (with individual scores and comments), and AI feedback.

Override Score (Optional)

If you disagree with the AI's assessment, enter your own score (0 to max points) and feedback. The attempt score automatically recalculates using your override.

Teacher Authority: The teacher's score always takes precedence over AI grading. The AI is a first-pass assistant — final authority rests with the instructor.

Course Catalog

Students can browse available courses and self-enroll.

Browse Available Courses

Click "Course Catalog" in the sidebar. You'll see course cards with titles, descriptions, sector tags, and duration.

Filter and Search

Use the search bar to find specific courses. Filter by institution if multiple are available.

Self-Enroll

Click "Enroll" on any available course. You'll be immediately enrolled and can start learning. Some courses may be restricted to your institution only.

Learning Experience

The course reader provides a clean, focused learning environment.

Open a Course

From "My Learning", click any enrolled course card. The course opens in a two-panel layout: module list on the left, content on the right.

Navigate Modules & Sections

Click any module in the left sidebar to view its sections. Use the Previous/Next buttons at the bottom to move between sections within a module.

Content Types

Sections can contain: rich text lessons, embedded videos (YouTube), downloadable files, or external links. The content area adapts to the type automatically.

Mark as Complete

After reading a module's content, click "Mark as Complete". Your progress updates automatically. The progress ring on your course card shows overall completion.

Assessments Tab

Switch to the "Assessments" tab in the sidebar to see and take exams for this course, or view your past attempt grades.

Taking Assessments

Assessments combine MCQ, essay, activity, and code questions in a single exam with one-at-a-time navigation.

Start an Assessment

Click "Take" on any available assessment. The exam opens in a full-screen modal with a timer (if time-limited).

Answer Questions One at a Time

Each question is shown individually. For MCQ: click an option. For essay/activity: type in the text area. For code: write your solution in the code editor. Navigate using Previous/Next or the numbered dots at the top.

Submit

Click "Submit All" when ready. MCQ items are graded instantly. Essay/activity/code items are evaluated by the platform's grading system — results appear shortly after.

Review Results

Click "View Grades" to see all your attempts. Click any attempt to review each item: see which MCQ you got right/wrong (with explanations), and view rubric-based feedback for essay/code items.

Instant Grading

MCQ items graded in milliseconds. Point-based scoring with weighted items.

AI Evaluation

Essay, activity, and code responses evaluated against structured rubrics with per-criterion scoring.

Tamper-Proof

Questions snapshotted at attempt start. Edits to the item bank don't affect in-progress exams.

Injection Protected

AI grading includes prompt injection protection — students cannot manipulate scoring via text tricks.

Certificates

Earn a professional PDF certificate upon completing all modules and passing all assessments.

Complete All Requirements

Mark all modules as complete AND pass all published assessments for the course. The system automatically detects when you've met all requirements.

Download Certificate

Once completed, a download button appears on your course card. Click it to generate and download your personalized PDF certificate.

Verify Authenticity

Each certificate includes a QR code that anyone can scan to verify its authenticity — no login required. The verification page confirms the student's name, course, and completion date.

Security Architecture

Enterprise-grade security built into every layer of the platform.

Authentication

  • • JWT-based stateless tokens (24h expiry)
  • • httpOnly cookies (XSS-safe)
  • • SameSite=Lax (CSRF protection)
  • • BCrypt password hashing (work factor 12)

Access Control

  • • Role-based permissions on every endpoint
  • • Institution-scoped data isolation
  • • Institution deactivation blocks all members
  • • Protected static file serving (JS/CSS)

Input Protection

  • • HTML sanitization (nh3) prevents Stored XSS
  • • Rate limiting on login (5 req/min per IP)
  • • Input length truncation (50K char limit)
  • • Parameterized SQL queries (no injection)

AI Safety

  • • Prompt injection detection & filtering
  • • Student responses sanitized before AI evaluation
  • • Score caps (AI cannot exceed max points)
  • • Structured prompts with clear boundaries

Scalability & Architecture

Designed for 10,000+ concurrent users with modern async architecture.

Async-First

Every I/O operation (database, storage, AI) is non-blocking. Built on Python's asyncio with FastAPI.

Connection Pooling

MySQL connection pool (20-100 connections) ensures efficient database access under heavy load.

Stateless

No server-side sessions. JWT tokens enable horizontal scaling — add servers without session sync.

AWS Infrastructure

S3 for storage, CloudFront CDN, Bedrock for AI, RDS for MySQL, auto-scaling EC2.

Background Processing

AI grading, PDF generation, and slide creation run as background tasks — never blocking user requests.

Frequently Asked Questions

How do I reset my password?

Contact your institution's administrator or staff member. They can reset your password from the Accounts management panel. For security, passwords cannot be recovered — only reset.

Can I retake an assessment?

Yes, if the instructor configured multiple attempts. The number of remaining attempts is shown on the assessment card. Each attempt pulls random questions from the item bank, so the exam is different each time.

How is my essay/code graded?

The platform evaluates your response against a structured rubric with specific criteria (e.g., correctness, completeness, code quality). Each criterion receives a score. Your teacher can also review and adjust the score if needed.

What happens if I run out of time during an exam?

The exam is automatically submitted with whatever answers you've provided. Unanswered questions receive zero points. You'll see a warning when one minute remains.

How do I get my certificate?

Complete all modules (mark each as done) and pass all assessments. Once both conditions are met, the system automatically marks your enrollment as "completed" and a download button appears on your course card.

Can someone verify my certificate is real?

Yes! Each certificate has a QR code. When scanned, it opens a public verification page that shows the student name, course, and completion date — no login required. This makes it easy to share with employers.

What browsers are supported?

The platform works on all modern browsers: Google Chrome, Mozilla Firefox, Apple Safari, and Microsoft Edge. A stable internet connection is required. The interface is responsive and works on mobile devices.
